# 05 — Checklist avant de publier chaque vidéo

Imprime-la, ou coche-la mentalement à chaque fois. Ça évite les erreurs qui
« tuent » une vidéo.

## 🎬 Avant le tournage
- [ ] J'ai une idée claire et un angle (voir `02-idees-videos.md`)
- [ ] Je sais quel sera le **moment fort** à mettre dans les 3 premières secondes
- [ ] La qualité d'enregistrement est bonne (au moins 1080p si possible)

## ✂️ Au montage
- [ ] La vidéo **commence par l'action la plus forte** (pas par « salut à tous »)
- [ ] J'ai coupé les temps morts (les gens décrochent vite)
- [ ] Le son est audible et pas trop fort / trop faible
- [ ] La vidéo n'est pas trop longue pour ce qu'elle raconte

## 🖼️ Miniature + titre (le plus important !)
- [ ] Miniature claire, 3-4 mots max, couleurs vives (voir `03-miniatures.md`)
- [ ] Miniature lisible en tout petit (test du téléphone)
- [ ] Titre court, honnête, avec le mot-clé important au début
- [ ] Le titre et la miniature **racontent la même chose** que la vidéo

## 📝 Description + tags
- [ ] Description de 2-3 phrases décrivant la vidéo (bon pour la recherche)
- [ ] Quelques mots-clés naturels (« Rocket League », « tuto aerial », le rang…)
- [ ] Lien vers une autre de ses vidéos (pour garder les gens sur la chaîne)

## 🚀 Après publication
- [ ] Je réponds aux premiers commentaires (l'algo aime l'interaction précoce)
- [ ] Je crée 1 Short à partir du meilleur moment de la vidéo
- [ ] Je note ce qui a marché / pas marché pour la prochaine fois

## 🔒 Sécurité (spécial mineur — 13 ans)
- [ ] Pas d'infos perso dans la vidéo (nom de famille, école, adresse, visage
      seulement si les parents sont d'accord)
- [ ] Compte géré / supervisé par un parent
- [ ] Commentaires surveillés par un adulte
- [ ] Paramètres de confidentialité vérifiés dans le compte Google
